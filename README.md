## ✨ О проекте

**BMI Calculator — Smart Health Assistant** — это современный русскоязычный калькулятор индекса массы тела, который помогает пользователю быстро рассчитать BMI и получить мягкие рекомендации по самочувствию, питанию и активности.

Проект делает акцент не на оценке человека по цифрам, а на спокойном и полезном объяснении результата:

- 💛 без давления и осуждения;
- 🧠 без медицинских диагнозов;
- 📊 с понятной категорией BMI;
- 🌱 с дружелюбными советами по образу жизни;
- ✨ с лёгкими CTA-вопросами для продолжения.

> **Важно:** BMI — это ориентир, а не медицинский диагноз. Для точной оценки здоровья стоит учитывать состав тела, самочувствие, анализы, уровень активности и другие факторы.

## 🚀 Возможности

| Возможность | Описание |
| --- | --- |
| 📏 Рост в см или м | Можно ввести `175`, `1.75` или `1,75`. |
| ⚖️ Вес в кг | Поддерживаются целые и дробные значения. |
| 👤 Пол и возраст | Опциональные поля для более персональных подсказок. |
| 🧮 Расчёт BMI | Формула: `BMI = вес / рост²`, результат округляется до 1 знака. |
| 🎨 Современный UI | Карточки, градиенты, адаптивная сетка и аккуратные CTA. |
| 🧪 Тесты | Проверяются нормализация, категории, расчёт и ошибки валидации. |

## 🟦🟩🟨🟥 Категории BMI

| Категория | Диапазон |
| --- | --- |
| 🟦 Недостаточный вес | BMI < 18.5 |
| 🟩 Норма | 18.5–24.9 |
| 🟨 Избыточный вес | 25–29.9 |
| 🟥 Ожирение | 30+ |

## 🖥️ Быстрый старт

### 1. Клонируй репозиторий


```bash

```

Перейди в браузере по адресу:

## 🧩 Основная логика

```js
BMI = weightKg / heightMeters ** 2
```

Пример:

```text
Вес: 70 кг
Рост: 1.75 м
BMI: 22.9
Категория: 🟩 Норма
```
