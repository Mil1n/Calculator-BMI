# BMI Calculator — Smart Health Assistant

Дружелюбный веб-калькулятор BMI на русском языке. Он принимает рост, вес, опционально пол и возраст, рассчитывает индекс массы тела и показывает мягкие рекомендации по образу жизни без медицинских диагнозов.

## Запуск

```bash
npm start
```

Открой `http://localhost:4173`.

## Проверка

```bash
npm test
```
